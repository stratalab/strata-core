# `hub` — command reference

| Command | Summary |
|---|---|
| [Read hub dataset](/docs/hub/get_dataset) | Read one StrataHub dataset card. |
| [Read hub info](/docs/hub/info) | Read the selected StrataHub's V1 capability advertisement. |
| [List hub datasets](/docs/hub/list_datasets) | List datasets from the selected StrataHub. |
| [List hub dataset refs](/docs/hub/list_refs) | List live refs for a StrataHub dataset. |
| [List yanked hub refs](/docs/hub/list_yanked) | List yanked refs from the selected StrataHub. |
